# Lab 4 - Bello

Static responsive landing page for the Bello insurance layout

## Project Structure

- `index.html` - semantic page markup
- `css/common.css` - shared variables, reset rules, accessibility states, and motion preferences
- `css/laptop.css` - base laptop/desktop layout
- `css/tablet.css` - tablet and medium-width layout rules
- `css/phone.css` - narrow mobile layout rules
- `assets/common/` - images and icons reused by all layouts
- `assets/laptop/` - desktop-only decorative images
- `assets/tablet/` - tablet-specific images, currently none because tablet reuses common assets
- `assets/phone/` - phone-specific images, currently none because phone reuses common assets
